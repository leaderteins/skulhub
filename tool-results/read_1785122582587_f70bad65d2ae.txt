     1→# EduManage Pro — School/University Management System
     2→
     3→## Project Overview
     4→Building a professional, world-class school/college/university management system
     5→tailored for Kenyan use cases (CBC curriculum, KES currency, 3-term calendar,
     6→M-Pesa-style payments, KCSE/KCPE tracking) and scalable worldwide.
     7→
     8→## Architecture
     9→- **Frontend**: Next.js 16 App Router, single `/` route (SPA-style view switching via sidebar)
    10→- **Styling**: Tailwind CSS 4 + shadcn/ui (New York), emerald/teal academic theme
    11→- **Database**: Prisma + SQLite
    12→- **State**: Zustand for active view, TanStack Query for server state
    13→- **Real-time**: (future) socket.io mini-service for live announcements
    14→
    15→## Modules
    16→1. Dashboard (stats, charts, calendar, recent activity)
    17→2. Students (admissions, profiles, enrollment, guardians)
    18→3. Staff (teachers & non-teaching, assignments, departments)
    19→4. Academics (classes, subjects, timetable, exams, grades — CBC + 8-4-4)
    20→5. Attendance (daily marking, reports, trends)
    21→6. Finance (fee structure, invoices, M-Pesa payments, scholarships, expenses)
    22→7. Communications (announcements, SMS/Email queue)
    23→8. Library (books, borrowing/returns)
    24→9. Transport (routes, vehicles, assignments)
    25→10. Reports & Analytics
