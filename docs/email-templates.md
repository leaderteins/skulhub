## Email Tips

### Best Practices:
1. **Personalize** — always use the school's name and the contact's name
2. **Keep it short** — 150-200 words max for cold emails
3. **One CTA** — one clear action per email (book demo, start trial, reply)
4. **Follow up** — 3 follow-ups maximum, spaced 3-4 days apart
5. **Time it right** — send Tuesday-Thursday, 9-11 AM or 2-4 PM EAT

### Subject Line Tips:
- Use emojis sparingly (1-2 per subject)
- Keep under 50 characters for mobile
- Create curiosity or urgency
- A/B test different subjects

### Tracking:
- Use a tool like Mailtrack (free) to see when emails are opened
- Log all interactions in a spreadsheet: School, Contact, Date Sent, Response
- Set reminders to follow up after 3 days
